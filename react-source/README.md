# Power Up 0 Flashcards (React)

115 picture flashcards from *Power Up Second Edition, Level 0*, grouped by the lesson
number in each card's top-right corner (Starter + Lessons 1–9).

Features: choose one or more lessons, flip cards (picture ↔ word), shuffle,
"Say it" / "Slowly" pronunciation (browser speech, British English), swipe and keyboard
(← → move, Space flip, P say).

## Run
    npm install
    npm run dev       # open the printed URL
    npm run build     # static site in dist/

Card data: `src/cards.js`. Pictures: `public/img/`.
