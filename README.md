# Power Up 0 Flashcards

React flashcard app for *Power Up Second Edition, Level 0*: 115 picture cards grouped by lesson
(Starter + Lessons 1–9), flip, shuffle and pronunciation.

Live site: https://dchankova.github.io/power-up-flashcards/

- `index.html` + `img/` — the app, ready to run (React loaded from a CDN, no build needed).
- `react-source/` — the same app as a Vite + React project (`npm install`, `npm run dev`;
  copy `img/` into `react-source/public/img/` first).
